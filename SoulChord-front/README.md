# SoulChord — AI 音乐电台桌面应用

> 本地 AI 音乐推荐 + 桌面宠物陪伴，打造属于你的 24 小时私人电台。

SoulChord 是一个基于 **AI Agent** 的桌面音乐应用。它不仅能根据你的听歌习惯和情绪推荐音乐，还附带一只 **可拖拽的桌面宠物**，为你的桌面增添一点温暖与陪伴。

---

## ✨ 主要特性

### 🎵 AI 音乐电台
- **AI 用户画像**：自动分析你的歌单，生成专属音乐偏好（曲风、歌手、年代、情绪）。
- **智能对话交互**：与 AI DJ 实时聊天，获得基于情境的歌曲推荐。
- **情境歌单生成**：根据时间、天气、情绪自动生成播放列表。
- **本地音乐播放器**：播放/暂停/切歌/进度控制/喜欢反馈，支持三种播放模式。
- **网易云音乐集成**：支持导入网易云歌单，同步音乐资产。

### 🐲 桌面宠物（桌宠）
- **悬浮透明宠物**：可爱宠物悬浮在桌面上，不影响其他窗口操作。
- **拖拽移动**：按住宠物即可将其拖到屏幕任意位置，松手播放点击动画。
- **自动状态切换**：
  - 10 秒无操作 → 播放“闲置1”动画（打哈欠等）
  - 20 秒无操作 → 播放“闲置2”动画（瞌睡等）
  - 点击宠物 → 显示主窗口（SoulChord 界面）
- **昼夜主题**：根据系统时间自动切换白天/夜晚素材。
- **对话气泡**：可显示来自 AI 的文字消息（预留接口）。
- **与主窗口联动**：单击宠物显示主窗口，拖动宠物隐藏主窗口，避免遮挡。

### 🎨 自定义素材
桌宠的动画完全由图片资源驱动，你可以替换 `public/assets/day/` 和 `public/assets/night/` 中的图片，轻松更换角色！

## 🧰 技术栈

| 层级 | 技术 |
|------|------|
| **桌面框架** | Electron（透明无边框窗口、置顶、托盘） |
| **前端框架** | Vue 3 + TypeScript + Vite |
| **状态管理** | Pinia |
| **UI 组件库** | Element Plus |
| **通信** | WebSocket（实时交互）+ HTTP REST API |
| **播放器** | HTML5 Audio API |
| **桌宠** | 原生 Canvas + JavaScript 动画状态机 |
| **打包** | electron-builder |
